## §3 关键坑（按发现顺序）

1. **DATE_TIME 双格式 + dayfirst 翻转**：P1 发电量/P2 气象是 `dd-mm-yyyy HH:MM`，P1 气象/P2 发电量是 ISO。`dayfirst=True` 混解析把 ISO 中 day≤12 的日期翻转（2020-06-01→2020-01-06），一度让缺槽统计完全失真（"3,259 槽却缺 1,059"的悖论）。修复：`io.parse_dt` 按首值探测格式整列解析，禁止 dayfirst 混解析。加了回归测试。
2. **lightgbm 装不上**：pip 走 `http_proxy` 被拒（WinError 10061），而 curl 同代理正常——疑似防火墙拦 python.exe 回环。绕过：curl 从清华源拉 wheel，`pip install --no-index` 本地装（4.7.0）。
3. **xgboost 3.x API 变更**：`early_stopping_rounds` 从 `fit()` 挪进构造器，TypeError。改为构造器传参。
4. **LSTM 塌缩**：未标准化特征（功率单位 W，量级 10⁴）→ 3 种子全塌到常数预测（RMSE≈10.5 kW ≈ 目标标准差）。修复：train 集统计标准化特征与目标，RMSE 回到 2.3–2.9 kW 量级。
5. **pandas 3.x Index 不可变**：`dt.hour` 返回 Index，布尔赋值 `irr[mask]=0` 抛 `TypeError: Index does not support mutable operations`。测试 fixture 改 `np.asarray`。
6. **白天停机统计粒度**：按原始槽计数时 Plant_2 全员 22/22 告警（10–277 槽）——事件是真的（正午辐照 0.8–1.0 时整块 AC=DC=0），但需 (a) 连续槽合并为事件 (b) 剔除同刻全队 ≥50% 记 0 的槽（站级事件）(c) 三级严重度分级（正常/告警/重点）替代二值 flag。
7. **诊断口径不能只看效率**：两站转换效率都全队均匀（P2≈0.979；P1≈0.098 是 DC 量纲问题），效率散点看不出故障；有效信号在完整率/停机/相对出力。P1 的 ×10.2 量纲异常本身作为数据质量发现单独报告。

## §4 实验设计要点

- 预测任务：y(t+1h)，特征只用 t 及以前；`nowcast`/`weather` 双口径；按 target_dt 切天 70/15/15 防泄漏。
- 基线含槽均值（日内周期强基线），避免高估模型增量。
- LSTM 3 种子集成，历史 val RMSE 换算回 W 画曲线。
- 诊断 5 维度（完整率/停机/效率/静态损耗/相对出力）+ MAD 稳健 z + 分级。
