# 基准评测报告 N3：光伏电站功率预测与损失诊断

> 数据：Kaggle Solar Power Generation Data（印度双电站，22+22 台逆变器，15min × 34 天）
> 环境：Python 3.12 / pandas 3.1 / scikit-learn / LightGBM 4.7 / XGBoost 3.4 / PyTorch 2.10 (CPU)
> 日期：2026-11-08（v1.1 增补同日；v1.2 增补 2026-11-11；v1.3 增补 2026-11-14）

## 摘要

1. 任务定义：给定 t 时刻信息预测 **t+1 小时（4×15min）站级 AC 功率**；按天时间序切分 train/val/test = 70/15/15，特征只用 t 及以前，无泄漏。
2. 两个特征口径：`nowcast`（时间编码 + 功率滞后）与 `weather`（+ 当刻辐照/温度，近似气象预报情形）。
3. LightGBM 两站最优：Plant_1 nRMSE **9.98%**（RMSE 2,700 W，R² 0.89）、Plant_2 **11.87%**（2,315 W，R² 0.83）。
4. 持久性基线 15.11% / 16.72%，槽均值基线 10.95% / 12.96%（v1.1 修正为仅用训练期统计）——昼夜节律主导，槽均值是必须越过的门槛。
5. LSTM×3 集成 10.64% / 12.50%，与 GBDT 同量纲未超越；34 天数据对深度模型偏少，且 LSTM 未标准化会塌缩到常数预测（RMSE≈10.5 kW，修复见工作记录）。
6. 天气特征增益稳定但小（-0.16pp / -0.25pp）；辐照-功率相关 0.995 / 0.911，是第一驱动特征。
7. 误差归因：正午（12-15 时）RMSE 最大（5,027 W / 3,912 W），夜间仅 300–760 W；辐照 >0.8 kW/m² 桶误差最大（P1 6,266 W）。
8. 逆变器诊断：Plant_1 检出**站级 DC 通道量纲偏大约 10.2 倍**（全队 AC/DC≈0.098）+ 2 台效率离群；Plant_2 检出 **14 台重点 + 8 台告警**，含 4 台 5/20–5/29 通讯中断（完整率 0.72）与重灾机 `Et9kgGMDl729KT4`（白天零出力 272 槽 / 34 次事件）。
9. 诊断规则要点：连续槽合并为停机事件、同刻全队 ≥50% 记 0 的槽剔除（站级事件不算单机故障）、MAD 稳健 z 分数（>3.5 告警、>4.5 重点）。
10. **（v1.1）多提前量**：LightGBM 从 15min 到 4h nRMSE 仅 8.4%→11.3%（P1），而持久性 8.6%→36.1%、R² 翻负——模型价值随提前量放大，4h 时仍保持 R² 0.86+。
11. **（v1.1）跨站迁移**：容量归一化是关键（ZeroShot 16.0%→12.1%）；7 天少样本在 P1→P2 追平域内（11.83% vs 11.87%），P2→P1 尚差 1.3pp。
12. **（v1.1）分位数预测**：LightGBM q10/q90 区间天然保守（覆盖 88.5% vs 名义 80%，共形校准 q̂=0）；白天覆盖≈名义，但强光桶覆盖塌到 45%——误差最大时段区间反而失效。
13. **（v1.2）条件保形把桶间覆盖极差砍半**：Mondrian-辐照桶 P1 0.469→0.202、P2 0.256→0.143，宽度仅 +3~8%；全局 CQR（q̂=0）对条件覆盖是空操作。
14. **（v1.2）云跳变事件是误差与区间可靠性的真正缺口**：5–11% 的样本贡献 23–40% MSE，事件 RMSE 2.3×、区间覆盖掉到 0.69–0.74；下坡高估 +3~4kW、上坡低估 −2~3.5kW（模型滞后于辐照突变）。
15. **（v1.2）物理混合不增益但可解释**：智慧持久性 P1 11.74%（强物理基线）/P2 16.47%（失效）；ML 残差混合不超纯 ML；误差 61–64% 集中在多变天 k_t 0.4–0.8，强光桶系统性低估 −2.8~−5.7kW。
16. **（v1.3）分组共形的软收缩才是正解**：`q_g = n/(n+k)·q̂_g + k/(n+k)·q_global`（k=20）把 P1 强光桶覆盖 1.000→0.773、桶间极差 0.202→0.151，宽度还降 2.7%；q̂ bootstrap 标准差 −48%/−44%。**v1.2 建议的"向邻桶借强度"被证伪**：真借（bw=1.0）反而把覆盖打到 0.545、极差 0.378——辐照桶分数非同分布，池化灌进大量 0 分数。
17. **（v1.3）全局共形校准被夜间点质量钉死**：校准集 45% 样本 |r|=1 且 CQR 分数=0（夜间 AC=0 恰落在 q10 下边界），名义 80% 分位数落进点质量 → 加法 q̂=0、乘法 λ=1.000 全是空操作，pinball+共形二段缩放只是把区间放大 21–34% 而未改善 P1 事件覆盖；白天专用校准（λ=1.063/1.153）才解锁。这解释了 v1.2 为何必须分组校准。
18. **（v1.3）Transformer 赢 LSTM 但没全面赢 GBDT，且增益多不来自时序**：同参数量（19.9k vs 21.1k）下 tr_small 在 4/4 配置优于 LSTM（−0.05~−0.95pp），长提前量优势更大；但 P1 两个提前量仍输 LightGBM（+0.62/+0.37pp），仅 P2 反超（−0.32/−0.48pp）。加深到 68.2k 反而 3/4 变差；把 16 步窗口打乱后 3/4 配置几乎无损（+0.00~+0.04pp），只有 P1 1h 退化 +0.78pp——大部分增益来自特征混合而非时序依赖。训练成本 2×。
19. 全部 **96 项单测**通过（v1.3 新增 48 项）；结果可由 `run_all.sh` 一键复现（00–15）。

## §1 数据与预处理

### 1.1 数据集

| 文件 | 行数 | 内容 |

| Plant_2_Weather_Sensor_Data.csv | 3,259 | 同上 |

时间范围 2020-05-15 ~ 2020-06-17（3,264 槽）。数据经 GitHub 镜像获取（Kaggle API 需凭据），`Plant_2_Weather` 镜像版混入第三方天气列且非 UTF-8，已抽取 6 个原始列重建（3,259 行与公开统计一致）。

### 1.2 已知坑（对复现重要）

1. **DATE_TIME 格式不统一**：4 个文件混用 `dd-mm-yyyy HH:MM` 与 ISO 两种格式。`dayfirst=True` 混解析会把 ISO 里 day≤12 的日期翻转（如 6 月 1 日 → 1 月 6 日），静默错 20+ 天数据。io.parse_dt 按首值显式探测格式整列解析。
2. **Plant_1 DC 量纲异常**：全队 AC/DC≈0.0979（Plant_2 为 0.979），DC 通道疑似整体 ×10 记录。站级指标不受影响（用 AC），诊断里显式报出。
3. 夜间功率为 0 占比约一半（正常）；发电量行数 < 22×3,264 有少量缺槽，缺槽不填补直接剔除（站级 3,158/3,259 有效槽）。

## §2 预测任务与协议

- **目标**：站级 AC 功率 y(t+4)（1 小时提前量）。
- **特征**（t 时刻及以前）：
  - `nowcast`：小时/年内日 sin-cos、ac_now、ac_lag{1,4,8,96}、4 步滚动均值（10 维）；
  - `weather`：+ 辐照、环温、组件温度、温差、irr_lag{1,4}（17 维）。
- **切分**：按目标时刻所在天 70/15/15 时间序切分（train 24 天 / val 5 天 / test 5 天）；同一天不跨集合；滞后特征允许来自更早集合（真实预测场景）。
- **容量代理**：站级 AC P99（Plant_1 27,057 W / Plant_2 19,506 W）；nRMSE = RMSE / 容量。
- **模型**：持久性（y(t+h)=y(t)）、槽均值（训练集按日内槽取均值）、Ridge、LightGBM、XGBoost、LSTM（窗口 16 步，3 种子集成）。
- **LSTM 细节**：特征与目标按 train 集统计标准化（不归一会塌缩到常数预测）；早停看验证 RMSE。

### 3.3 观察

- GBDT > 线性 > 持久性；LSTM 与 GBDT 同量纲，Plant_2 nowcast 略胜 LightGBM 但 weather 口径反被拉开。
- 槽均值 10.95%/12.96%（v1.1 起仅用训练期统计；v1.0 曾误含测试期均值为 10.52%/12.14%）：日内周期贡献极大；LightGBM 的真实增量约 1.0pp / 1.1pp（R² 提升 0.02–0.03）。
- 天气口径两站一致小幅更优——当刻辐照对未来 1h 仍有信息量（云况持续性）。

### 3.4 （v1.1）多提前量退化：15min → 4h

LightGBM（weather）与持久性基线随提前量的 nRMSE（%容量）：

| 提前量 | P1 LGBM | P1 Pers | P2 LGBM | P2 Pers |
|---|---|---|---|---|
| 15min | 8.37 | 8.56 | 10.66 | 12.15 |
| 30min | 9.82 | 11.64 | 11.94 | 14.85 |

- **技巧随提前量缓降、基线快速失效**：4h 时 LightGBM R² 仍 0.863/0.816，持久性 R² 已翻负（-0.41/-0.39）。模型价值随提前量放大——15min 时仅赢 0.2pp，4h 时赢 25pp。
- 15min 处持久性几乎追平模型（8.56 vs 8.37）：超短提前量场景可直接用持久性，建模增量集中在 30min 以上。
- nowcast 与 weather 口径在长提前量基本打平（4h 时 10.99 vs 11.25），当刻天气的信息优势随提前量衰减。

### 3.5 （v1.1）跨站迁移与少样本适配

目标站测试 nRMSE（%容量），LightGBM weather 口径：

| 变体 | P1→P2 | P2→P1 |
|---|---|---|
| Persistence（目标站） | 16.72 | 15.11 |
| ZeroShot（原值） | 16.02 | 14.54 |
| ZeroShot（容量归一化） | 12.07 | 11.64 |

- **容量归一化是迁移的第一杠杆**：两站容量差 27.1 vs 19.5 kW，原值零样本几乎不赢持久性（16.0% vs 16.7%）；功率特征/目标按各自容量归一后直接降到 12.1%。
- **P1→P2 的 7 天少样本追平域内**（11.83% vs 11.87%，目标站天气规律同质）；P2→P1 迁移 7 天适配后仍差 1.3pp（11.28% vs 9.98%）——P1 的 DC 量纲异常/更大容量使目标域更难。
- 与 N2 涡扇跨子集迁移（零样本缺口 +8~21）对比：同区域同机型的光伏电站间迁移性显著更好，"归一化 + 少量目标域数据"即可实用。

### 3.7 （v1.2）条件保形：分桶覆盖均匀化

针对 §3.6 的"总覆盖 0.88 但桶间极差大"，对同一组 q10/q50/q90 分位数模型比较五种区间口径（名义 80%）：

| 方法 | P1 覆盖/宽度 | P1 桶间极差(辐照) | P1 昼夜极差 | P2 覆盖/宽度 | P2 桶间极差(辐照) | P2 昼夜极差 |
|---|---|---|---|---|---|---|
| raw q10–q90 | 0.885 / 4783W | 0.469 | 0.181 | 0.887 / 4185W | 0.256 | 0.175 |
| 全局 CQR（=v1.1） | 0.885 / 4783W | 0.469 | 0.181 | 0.887 / 4185W | 0.256 | 0.175 |
| Mondrian-辐照桶 | 0.900 / 4970W | **0.202** | 0.151 | 0.892 / 4517W | **0.143** | 0.167 |
| Mondrian-昼夜 | 0.897 / 4961W | 0.482 | 0.156 | 0.923 / 4793W | 0.244 | 0.104 |
| Mondrian-辐照×昼夜 | 0.912 / 5062W | 0.202 | **0.126** | 0.906 / 4661W | 0.166 | 0.137 |

1. **全局 CQR 对本问题是空操作**（q̂=0）：分位数模型本身已保守，全局校准无从修正桶间不均——v1.1 的"免校准"结论只对总覆盖成立，对条件覆盖不成立。
2. **Mondrian-辐照桶把桶间极差砍半以上**（P1 0.469→0.202、P2 0.256→0.143），代价仅 +150～+330W 宽度（+3～8%）。强光桶 P1 0.455→1.000（n=22，小样本校准过冲）、P2 0.727→0.818，夜间从过宽回缩。
3. **分组要跟失效模式走**：昼夜分组只修昼夜差（极差 0.181→0.151），对辐照桶差几乎无效；组合分组最平（P1 昼夜极差 0.126）但样本被切细，强光桶 n=22 的校准分位数噪声大（P1 强光桶覆盖直接过冲到 1.0）——**分组粒度受最小样本量约束**，极端桶宜向邻桶借强度（本次未做）。

### 3.8 （v1.2）云跳变极端事件：误差与区间可靠性的真正缺口

测试集相邻 15min 槽 |ΔP| ≥ 20% 容量判为云跳变（ramp）事件：

| 指标 | Plant_1 | Plant_2 |
|---|---|---|
| 事件数（占比） | 26（5.4%） | 53（11.0%） |
| 事件 RMSE / 平稳 RMSE | **5,613 / 2,428**（2.3×） | **4,424 / 1,896**（2.3×） |
| 事件区间覆盖 / 平稳 | **0.692 / 0.896** | **0.736 / 0.906** |
| 下坡偏差（云遮，n） | **+3,801W**（16） | **+2,945W**（28） |
| 上坡偏差（云散，n） | **−3,539W**（10） | **−2,070W**（25） |

1. **5–11% 的样本贡献了 23–40% 的 MSE**（§3.9 分解）：事件 RMSE 是平稳段的 2.3 倍，区间覆盖掉到 0.69–0.74——即使 CQR 区间在事件处自动加宽到 9,400–12,000W（平稳段的 2.2–2.8 倍），仍追不上误差膨胀。
2. **误差方向不对称且成对出现**：云遮（下坡）高估 +3~4kW、云散（上坡）低估 −2~3.5kW——模型滞后于辐照突变约一个以上时间步，沿用了"上一时刻是晴天"的惯性。这是 §4"云况突变建模是改进方向"的定量证据。
3. **最坏案例集中在高辐照时段**（P1 2020-06-15 13:15 与 16:00，单步 |ΔP|≈9–10 kW）：恰是 §3.6 强光桶区间失效、§4 正午误差最大的同一群事件——三个口径指向同一失效机制。

### 3.9 （v1.2）晴空物理混合：物理基线可解释但不增益；误差集中于"多变天"

物理侧（无坐标依赖）：训练期逐槽 95 分位辐照包络 → 晴空指数 k_t(t) → **智慧持久性** P_phys(t+1h)=β·k_t(t)·Ĝ(slot(t+1h))。混合侧：LightGBM 学习 P−P_phys 残差后回加。

| 方法 | P1 nRMSE | P2 nRMSE |
|---|---|---|
| 持久性 | 15.11% | 16.72% |
| 智慧持久性（物理） | 11.74% | 16.47% |
| LightGBM_weather | **9.98%** | **11.87%** |
| 物理+ML 残差混合 | 10.33% | 12.04% |

最优模型（LightGBM_weather）测试集残差分解：

| 分量 | P1 MSE 份额 / 偏差 | P2 MSE 份额 / 偏差 |
|---|---|---|
| k_t<0.4（阴天） | 10.6% / +672W | 21.7% / +346W |
| **k_t 0.4–0.8（多变天）** | **64.1% / +685W** | **60.9% / +46W** |
| k_t>0.8（晴天） | 25.3% / −988W | 17.4% / −302W |
| ramp 事件（5.4%/11.0% 样本） | 23.5% / +978W | 40.3% / +580W |
| 按辐照桶偏差 | [0.8,∞) 桶 **−5,733W** | [0.8,∞) 桶 **−2,750W** |

1. **智慧持久性在 P1 是强物理基线**（15.11%→11.74%，仅靠"当前晴空指数 × 目标槽晴空形状"），但在 P2 几乎无效（16.72%→16.47%）——P2 的云况时间自相关更弱，k_t 的 1h 持久性假设失效更快。
2. **残差混合不增益**（10.33% vs 9.98%、12.04% vs 11.87%）：LightGBM 的特征里已有辐照/温度/滞后，物理项不提供增量信息，反而多一层拟合噪声。**负结果：先验物理在特征完备的 GBDT 上没有免费午餐**；混合的价值在可解释性（β、k_t 可以画出来）与特征缺失时的兜底。
3. **误差的主战场是"多变天"而非阴/晴**：k_t 0.4–0.8 桶贡献 61–64% MSE（样本约 1/3）；强光桶系统性**低估** −2.8~−5.7kW，与 §3.8 的云遮高估互补（同一滞后机制的两面：平段低估、突变段高估）。

### 3.10 （v1.3 E29）分组共形的最小样本量平滑：软收缩有效，"借邻桶"被证伪

§3.7 结论 3 留下"极端桶宜向邻桶借强度（本次未做）"。本实验在同一组 q10/q90 分位数模型上比较 6 种 q̂ 生成方式，校准集 n=480，稀疏桶均为强光桶（P1 n=22 / P2 n=25，n_min=30）。名义覆盖 0.80。

| 方法 | P1 总覆盖/宽度 W | P1 稀疏桶覆盖 | P1 桶间极差 | P2 总覆盖/宽度 W | P2 稀疏桶覆盖 | P2 桶间极差 |
|---|---|---|---|---|---|---|
| global（全组同一 q̂） | 0.885 / 4783 | 0.455 | 0.469 | 0.887 / 4185 | 0.727 | 0.256 |
| **raw（v1.2 组内独立）** | 0.900 / 4970 | **1.000**（过冲） | 0.202 | 0.892 / 4517 | 0.818 | **0.143** |
| min_n（硬阈值回退全局） | 0.874 / 4611 | 0.455 | 0.469 | 0.890 / 4481 | 0.727 | 0.208 |
| **shrink（软收缩 k=20）** | **0.889 / 4834** | **0.773** | **0.151** | **0.892 / 4402** | **0.818** | **0.143** |
| pool（邻桶分数池化 bw=1） | 0.889 / 4824 | 0.545 | 0.378 | 0.892 / 4286 | 0.818 | 0.238 |
| pool_shrink | 0.889 / 4819 | 0.545 | 0.378 | 0.892 / 4275 | 0.818 | 0.238 |

1. **软收缩是双赢**：`q_g = n/(n+k)·q̂_g + k/(n+k)·q_global`。P1 稀疏桶覆盖 1.000→0.773（与名义偏差 0.200→0.027），桶间极差 0.202→0.151（比 v1.2 更平），宽度反而 4970→4834 W（−2.7%）；P2 保持 0.818 / 0.143 不变、宽度 4517→4402 W（−2.5%）。更准、更平、更窄同时成立。
2. **q̂ 抽样噪声确实被压住**：300 次组内 bootstrap 下稀疏桶 q̂ 标准差 P1 813→426 W（−48%）、P2 549→305 W（−44%）。但校准集重抽的**测试覆盖**方差 P1 从 0.956±0.080 变成 0.725±0.101，反而略升——raw 的 q̂ 大多饱和在"覆盖 = 1.0"的截断区（偏差大、方差被掩盖），收缩把工作点拉回覆盖对 q̂ 敏感的区域。**这是用一点可见方差换掉大幅系统偏差**，不是免费降方差。
3. **v1.2 的直觉建议被证伪**：真正"向相邻辐照桶借强度"（pool，bw=1.0）在 P1 把稀疏桶覆盖打到 0.545、极差恶化到 0.378。原因是辐照桶的分数分布根本不同分布（弱光桶 q̂≈0、强光桶 q̂=3900 W），池化把大量 0 分数灌进强光桶，把 q̂ 拉低造成欠覆盖。带宽敏感性极陡：bw 0.5→1.0 时 P1 稀疏桶覆盖 0.864→0.545、极差 0.090→0.378；只有"几乎不借"（bw≈0.5）才有效，工程窗口过窄，不可靠。
4. **min_n 硬阈值同样不行**：稀疏桶直接回退全局 q̂=0，覆盖从过冲 1.000 翻成欠覆盖 0.455、极差回到 0.469；且阈值附近跳变（n_min 20→30 结果直接翻转）。软收缩的连续权重避免了这个悬崖。
5. **超参不敏感**：shrink 在 k∈[5,20]（P1）、k∈[5,40]（P2）整个平台都优于 raw，k≥40 才退化为近似全局；k 取"目标最小样本量"量级即可，无需精调。组合分组（辐照×昼夜）下平滑也不增益（P1 极差 0.202→0.258）。
6. **另一半原因是分布偏移，平滑无法解决**：强光桶 `q̂_val` / `q̂_test` = 3900 / 2779 W（差 1121 W，P1）、776 / 1401 W（差 625 W，P2）；[0.5,0.8) 桶差 426–483 W。只用校准集的任何平滑都消不掉这部分，需要更长校准窗或漂移监测。

### 3.11 （v1.3 E30）pinball + 共形二段缩放：全局校准被夜间点质量钉死

把"第一段按 pinball 锐度选分位对"与"第二段共形乘性因子 λ"解耦，候选为 [q05,q95]/[q10,q90]/[q15,q85]/[q20,q80]，共 8 个分位数模型/站。评价含 §3.8 的 ramp 事件覆盖（P1 26 个 / P2 53 个）。

| 方法 | P1 覆盖/宽度 W | P1 ramp 覆盖 | P1 极差 | P2 覆盖/宽度 W | P2 ramp 覆盖 | P2 极差 |
|---|---|---|---|---|---|---|
| raw q10–q90 | 0.885 / 4783 | 0.692 | 0.469 | 0.887 / 4185 | 0.736 | 0.256 |
| add（全局 CQR） | 0.885 / 4783 | 0.692 | 0.469 | 0.887 / 4185 | 0.736 | 0.256 |
| mult（全局 λ） | 0.885 / 4785 | 0.692 | 0.469 | 0.887 / 4186 | 0.736 | 0.256 |
| **add_group（v1.2 Mondrian）** | 0.900 / 4970 | **0.769** | **0.202** | 0.892 / 4517 | 0.774 | **0.143** |
| mult_group（分桶 λ） | 0.868 / 4590 | 0.615 | 0.469 | 0.892 / 4515 | 0.792 | 0.208 |
| two_stage（pinball+λ） | 0.921 / 5788 | 0.692 | 0.427 | 0.929 / 5611 | 0.811 | 0.207 |
| two_stage_group | 0.885 / 4805 | 0.654 | 0.395 | 0.927 / 5755 | **0.849** | **0.143** |
| two_stage_shrink | 0.897 / 5008 | 0.654 | 0.395 | 0.923 / 5685 | 0.830 | 0.169 |

1. **全局共形（加法 q̂=0 W、乘法 λ=1.000）都是空操作，机制首次查清**：校准集 **45.0% 的样本满足 |r|=1 且 CQR 分数 = 0**（夜间 AC=0、q10 预测 0，真值恰落在下边界），在分数分布上形成一个点质量；名义 80% 的共形分位数正好落进这堆点质量，于是 λ 被钉死在 1.0、q̂=0。这也解释了 v1.2 为什么"全局 CQR 无效而 Mondrian 有效"——分组把夜间点质量隔离到独立桶，白天桶的校准才解锁。**白天专用校准是直接证据**：λ=1.063 / 1.153、q̂=178 / 608 W，白天覆盖从 0.795 / 0.806 抬到乘性 0.821 / 0.868、加法 0.808 / 0.872（宽度 +6% / +15%）。（`mult` 相对 `raw` 宽度 +2 W 不是校准生效，是少数 q10>q90 分位数交叉样本被半宽下限夹到 0，覆盖率逐点未变；单测 `test_apply_scale_clamps_crossed_quantiles` 钉死。）
2. **pinball 第一段选了最宽的一对 [q05,q95]**：验证集锐度 380.8 / 431.3 最小（覆盖 0.910 / 0.902），其余候选 634–974。但第二段 λ 仍是 1.0，净效果只是把区间整体放大 21% / 34%，总覆盖反而涨到 0.921 / 0.929（离名义 0.80 更远）。**pinball 锐度衡量分位数头的标定质量，不等于区间效率**；对一个本就保守的模型，它会偏爱更宽的对。
3. **二段缩放没解决事件缺口**：P1 ramp 覆盖 0.692 与 raw 完全相同；P2 到 0.811（+0.075）却要付 +34% 宽度。按"每 +1% 宽度换来的 ramp 覆盖百分点"算，v1.2 的 add_group 最划算（P1 0.077/4% ≈ 1.98、P2 0.038/8% ≈ 0.48），two_stage 为 0 / 0.22。two_stage_group 在 P2 拿下全场最高事件覆盖 0.849，但 P1 反而掉到 0.654，站间不一致。
4. **乘性缩放保留逐点异方差**：raw 的事件/平稳宽度比 2.75 / 2.66，乘性口径维持 2.45–2.81；加成式在 q̂≠0 时会压平该比值（单测 `test_apply_scale_preserves_center_and_width_ratio` 钉死）。本数据集 q̂=0，两种口径的差异根本没有机会显现——**机制存在但数据不给机会**的负结果。
5. **可迁移的教训**：夜间占比过半（52–53%）的光伏功率数据上，全局共形先天失效；应直接做分组校准（§3.7 + §3.10 的软收缩），而非叠加二段缩放。二段缩放在校准分数无点质量的场景（N2 涡扇 RUL）能免费改善欠覆盖，迁移前必须先查分数分布是否退化。

### 3.12 （v1.3 E31）Transformer 对比：赢 LSTM、未全面赢 GBDT，增益多不来自时序

用**同一个训练器**训练 LSTM 与两种 Transformer（标准化、优化器、早停、batch、种子、建模前 RNG 全部一致），唯一变量是网络结构；LightGBM 作非序列参照。weather 口径、两站 × {1h, 4h} × 3 种子集成。

| 站 / 提前量 | LightGBM | LSTM (21.1k) | tr_small (19.9k) | tr_deep (68.2k) | tr_small + 时序打乱 |
|---|---|---|---|---|---|
| P1 / 1h | **9.98** | 10.64 | 10.60 | 10.84 | 11.38 |
| P1 / 4h | **11.25** | 12.51 | 11.62 | 12.68 | 11.66 |
| P2 / 1h | 11.87 | 12.50 | 11.55 | **11.53** | 11.55 |
| P2 / 4h | 12.43 | 12.80 | **11.95** | 12.03 | 11.98 |

（nRMSE %，越小越好；括号为可训练参数量）

1. **协议对齐已验证**：建模前固定 seed 后，LSTM 1h 复现 v1.0 的 10.64% / 12.50%；tr_small 参数量 19,921 反而比 LSTM 21,057 少 5%，是真正的等预算对比。训练成本 tr_small 8–14 s / 种子 vs LSTM 4–6 s（约 2×），tr_deep 15–20 s（3–4×）。
2. **同参数量下 Transformer 4/4 优于 LSTM**：ΔnRMSE = −0.05 / −0.88 / −0.95 / −0.84 pp，且**提前量越长优势越大**（1h P1 几乎打平，4h 与 P2 全部约 0.85–0.95pp）。这修正了 v1.0"深度模型都不行"的笼统印象——不行的是循环结构，不是序列建模本身。
3. **仍未全面超过 LightGBM**：P1 两个提前量都输（+0.62 / +0.37pp），只有 P2 反超（−0.32 / −0.48pp）。P2 的优势虽大于 3 种子 RMSE 波动（22–31 W ≈ 0.1–0.16pp），但站间方向不一致且幅度 <0.5pp。**34 天数据下 GBDT 仍是默认推荐，Transformer 不是免费升级**。
4. **加深反噬**：tr_deep 参数量 3.4×，却在 3/4 配置比 tr_small 更差（P1 4h 11.62→12.68，+1.06pp 最明显），仅 P2 1h 基本持平。容量不是瓶颈，更多层在小样本上只是多一层过拟合。
5. **时序打乱消融揭示增益来源**：把 16 步窗口按固定置换打乱后，P1 1h 明显退化 +0.78pp（10.60→11.38，种子 std 70→144 W），但 P1 4h +0.04、P2 1h +0.00、P2 4h +0.03 —— **3/4 配置几乎无损**。即注意力只在 P1 短提前量真正用上时序排列，其余优势来自"带位置编码的特征混合/非线性变换"而非长程依赖。特征里已有 `ac_lag1/4/8/96` 与 `hour_sin/cos`，窗口内的排列信息高度冗余。
6. 与 N2 v1.2"Transformer 小数据负收益"对照，本结果是更细的版本：**赢 LSTM、输/平 GBDT、增益不来自时序、成本 2×**。工程建议：小样本表格时序任务先上 GBDT；只有需要统一序列架构（多变量、多步、跨站共享 backbone）时，Transformer 的 2× 训练成本才值得付。

## §6 结论与展望

1. 1 小时提前量预测以 LightGBM 为推荐模型（nRMSE 10%/12%），天气特征值得保留；部署前需补天气预报口径验证。
2. 槽均值是强基线，论文/面试对比务必带上，避免高估深度模型贡献。
3. 诊断管线的价值在"多维证据 + 分级"：效率维度在本数据集几乎无区分度，完整率/停机/相对出力才是有效信号；Plant_1 的量纲异常属于数据质量类发现。
4. （v1.1）提前量越长建模价值越大：4h 预报 LightGBM 仍 R² 0.86+ 而持久性失效；超短提前量（15min）可直接用持久性。
5. （v1.1）跨站部署成本低：容量归一化 + 1~7 天目标站数据即可接近域内水平；无需从头训练。
6. （v1.1→v1.2 修正）概率预测用 LightGBM 分位数总覆盖保守免校准，**但条件覆盖必须分桶校准**：Mondrian-辐照桶把桶间极差砍半（0.47→0.20），否则强光时段区间不可信。
7. （v1.2）误差治理优先级：多变天（k_t 0.4–0.8，61–64% MSE）> 云跳变事件（5–11% 样本、23–40% MSE、区间失效）> 阴/晴平段。云跳变的滞后偏差（下坡高估/上坡低估）指向"辐照临近时序特征或短临外推"改进方向。
8. **（v1.3）条件覆盖的最终配方 = Mondrian 分组 + 小样本软收缩**：先按辐照桶分组隔离夜间点质量（§3.7），再对稀疏桶 q̂ 向全局收缩（§3.10），k 取目标最小样本量量级即可；不要用邻桶池化或 min_n 硬阈值。校准窗自身的分布漂移（强光桶 q̂ 差 625–1121 W）是下一个待解问题。
9. **（v1.3）概率校准前先查分数分布有没有点质量**：夜间零出力占比过半的数据上，全局 CQR / 乘性缩放都会退化成空操作；二段缩放（pinball 选对 + λ）在本库是负结果，v1.2 的分组加法校准用 +4~8% 宽度换到的事件覆盖提升（+0.038~0.077）性价比最高。
10. 未做项：真日前预测（需天气预报源）、组串级根因分析、长校准窗与分布漂移监测、事件级自适应区间（ramp 覆盖 0.69–0.85 仍是最大缺口）、Transformer 的更长序列/更大样本验证。
