# 光伏电站功率预测与损失诊断（N3）

基于 Kaggle 公开的印度双光伏电站数据（逆变器级发电量 + 站级气象，15 分钟粒度，34 天），
完成三件事：

1. **功率预测**：提前 1 小时（4 步）预测站级 AC 功率，常数/槽均值/持久性基线 → Ridge → LightGBM/XGBoost → LSTM（3 种子集成），严格按天时间序切分（70/15/15）防泄漏；
2. **逆变器损失诊断**：DC/AC 转换效率 + 线性静态损耗拟合（AC = a·DC + b）+ 数据完整率 + 白天停机事件 + 相对出力，MAD 稳健 z 分数分级告警；
3. **误差归因**：测试误差按辐照强度与时段分桶，定位预测薄弱环节；
4. **（v1.1）深化**：多提前量退化曲线（15min→4h）、跨站迁移与少样本适配（容量归一化 + 1~7 天目标站数据）、LightGBM 分位数概率预测（q10/q50/q90 + 共形校准）。
5. **（v1.2）深化**：Mondrian 条件保形（分桶覆盖均匀化）、云跳变极端事件剖析（ramp 检测/区间可靠性/案例图）、晴空物理混合（智慧持久性 + ML 残差分解）。
6. **（v1.3）深化**：分组共形的最小样本量平滑（软收缩 vs 邻桶池化 vs 硬阈值）、pinball + 共形二段缩放（含夜间点质量机制诊断）、轻量 Transformer 与 LSTM 等协议对比（含时序打乱消融）。

## 数据

- Kaggle [`anikannal/solar-power-generation-data`](https://www.kaggle.com/datasets/anikannal/solar-power-generation-data)（约 11 MB）

## 主要结果

**1 小时提前量站级 AC 功率预测**（测试集，nRMSE = RMSE / 容量代理(AC P99)）：

| 模型 | Plant_1 nRMSE | Plant_2 nRMSE |
|---|---|---|
| 持久性基线 | 15.11% | 16.72% |
| 槽均值基线 | 10.95% | 12.96% |
| Ridge | 11.44% | 12.85% |
| **LightGBM（含天气）** | **9.98%** | **11.87%** |
| XGBoost（含天气） | 10.53% | 11.89% |
| LSTM×3 集成（含天气） | 10.64% | 12.50% |

**损失诊断**：
- Plant_1：发现站级 DC 通道量纲异常（AC/DC≈0.098 ≈ 1/10.2，疑似 DC 记录放大 10 倍）；2 台效率离群机组（`bvBOhCH3iADSZry` 重点、`1BY6WEcLGh8j5v7` 告警）。
- Plant_2：14 台重点告警 + 8 台告警；4 台 5/20–5/29 通讯中断（完整率 0.72）；重灾机组白天零出力 272 槽/34 次事件（`Et9kgGMDl729KT4`）。

**误差归因**：正午时段 RMSE 最高（P1 5,027 W / P2 3,912 W），夜间仅 300–760 W；辐照 >0.5 kW/m² 的强光桶误差显著放大。

## 结论

1. 提前 1 小时预测：LightGBM（时间编码 + 功率滞后 + 天气）两站最优，nRMSE 10.0% / 11.9%，较持久性基线降 5 个百分点。
2. 槽均值基线（仅用日内时刻）已达 11.0% / 13.0%——昼夜节律主导，任何模型必须先赢它才算有效。
3. LSTM 与 GBDT 同量纲竞争但未超越（34 天数据对深度模型偏少）；3 种子集成方差 <2%。
4. 天气特征带来稳定小幅增益（nowcast→weather：-0.16pp / -0.25pp），辐照是第一驱动（与 AC 相关 0.99 / 0.91）。
5. 误差集中在正午强光时段——恰好是发电量大头，预测价值最高也最难。
6. 诊断管线在 Plant_1 抓出 DC 量纲异常 + 2 台离群机组，在 Plant_2 抓出通讯中断 4 台 + 白天停机重灾 14 台，可运维复现。

**v1.1 深化结论**：

7. 提前量越长建模价值越大：4h 处 LightGBM 仍 R² 0.86+（nRMSE 11.3%），持久性已 36% 且 R² 翻负；15min 处两者打平，超短提前量直接用持久性。
8. 跨站部署成本低：容量归一化是第一杠杆（ZeroShot 16.0%→12.1%）；再加 1~7 天目标站数据，P1→P2 可追平域内模型。
9. 概率预测用 LightGBM 分位数即可（区间天然保守，覆盖 88.5% vs 名义 80%，免校准）；但强光时段覆盖塌到 45%——误差最大的时段区间最不可信，部署时需明示。

**v1.2 深化结论**：

10. **条件保形把桶间覆盖极差砍半**：Mondrian-辐照桶 P1 0.469→0.202、P2 0.256→0.143（宽度仅 +3~8%）；全局 CQR（q̂=0）对条件覆盖是空操作。小样本桶会过冲（P1 强光桶 0.455→1.000，n=22）。
11. **云跳变是误差与区间可靠性的真正缺口**：5–11% 样本贡献 23–40% MSE，事件 RMSE 2.3×、区间覆盖掉到 0.69–0.74；下坡高估 +3~4kW / 上坡低估 −2~3.5kW——模型滞后于辐照突变。
12. **物理混合不增益但可解释**：智慧持久性 P1 11.74%（强物理基线）/P2 16.47%（失效）；ML 残差混合不超纯 ML；误差 61–64% 集中在多变天 k_t 0.4–0.8。

**v1.3 深化结论**：

13. **分组共形要"向全局收缩"而不是"向邻桶借强度"**：软收缩 k=20 把 P1 强光桶覆盖 1.000→0.773、桶间极差 0.202→0.151，宽度 −2.7%，q̂ bootstrap 标准差 −48%；v1.2 建议的邻桶池化（bw=1.0）反把覆盖打到 0.545（辐照桶分数非同分布），min_n 硬阈值则从过冲翻成欠覆盖 0.455。k∈[5,20/40] 全平台优于 raw。
14. **全局共形校准被夜间点质量钉死**：校准集 45% 样本 |r|=1 / CQR=0（夜间 AC=0 恰在 q10 下边界）→ 加法 q̂=0、乘法 λ=1.000 全为空操作；pinball 第一段只会选出更宽的 [q05,q95]，二段缩放放大区间 21–34% 却没改善 P1 事件覆盖。白天专用校准 λ=1.063/1.153 才解锁——这正是 v1.2 Mondrian 有效的机制原因。
15. **Transformer 赢 LSTM、未全面赢 GBDT，增益多不来自时序**：等参数量（19.9k vs 21.1k）下 4/4 配置优于 LSTM（−0.05~−0.95pp），但 P1 仍输 LightGBM 0.37–0.62pp、仅 P2 反超 0.32–0.48pp；加深到 68.2k 反而 3/4 变差；把 16 步窗口打乱后 3/4 配置几乎无损（只有 P1 1h +0.78pp）。训练成本约 2×，小样本仍推荐 GBDT。
